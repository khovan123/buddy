## Roadmap Theo Content Type

### Resource MVP

**Goal:** Chung minh nhanh buyer confidence va conversion tren loai content de implement nhat.

**Core experience:**

- Resource detail page co `Honest Fit Card` gan CTA.
- Hien `Best For / Not For` ro rang, ngan, trung thuc.
- Hien `Start Here` voi 2-3 buoc hoc sau khi mua.
- Them `Content Receipt`: so file/trang, topics covered/not covered, last updated, creator trust.
- Them `Verified Fit` basic khi resource co du fit fields va metadata co ban.

**Creator workflow:**

- Them `FitEditor` vao create/edit resource form.
- Creator nhap hoac approve:
  - `bestFor`
  - `notFor`
  - `startHere`
  - topics covered
  - topics not covered
- Ban dau cho manual input, sau do them AI suggestion.

**Student workflow:**

- Student vao resource detail.
- Doc `Best For / Not For`.
- Xem `Start Here`.
- CTA doi tu `Buy now` thanh `Buy & start review` hoac `Start this study step`.

**Success metrics:**

- Resource detail purchase conversion.
- CTA click rate tren content co Honest Fit Card.
- Save rate va preview interaction.
- Ty le creator dien day du fit fields.

### Tutorial Expansion

**Goal:** Bien tutorial thanh guided lesson sequence, khong chi video/content detail.

**Core experience:**

- Tutorial detail page co `Honest Fit Card`.
- `Start Here` mapping theo video/step/chapter.
- Them `What you will master` cho tung tutorial hoac tung step.
- Hien AI-generated chapter/step preview neu transcript/extraction san sang.
- CTA: `Buy & start lesson 1`, `Continue with step 1`, hoac `Start guided tutorial`.

**Creator workflow:**

- Tutorial builder them fields cho:
  - learning outcomes
  - prerequisites
  - step order
  - bestFor/notFor theo tutorial
  - optional startHere per step
- AI co the goi y outcomes va chapter preview tu transcript/metadata.

**Student workflow:**

- Student biet tutorial phu hop voi trinh do nao.
- Student biet mua xong nen xem phan nao truoc.
- Sau purchase, app dua vao lesson/step dau tien thay vi chi ve library.

**Success metrics:**

- Tutorial purchase conversion.
- Step-1 start rate sau purchase.
- Tutorial completion/continue rate.
- So lan dung AI prompt lien quan tutorial.

### Collection As Learning Path

**Goal:** Doi collection tu bundle/catalog group thanh `Learning Path` co thu tu, checkpoint va gia tri ro rang.

**Core experience:**

- Collection detail page hien path overview:
  - estimated time
  - number of checkpoints
  - included resources/tutorials
  - recommended order
  - final outcome
- `Best For / Not For` o cap path.
- `Start Here` la checkpoint dau tien.
- CTA: `Start this learning path`.

**Creator workflow:**

- Collection builder them roadmap/sequence editor.
- Creator sap xep resources/tutorials theo checkpoint.
- Moi checkpoint co:
  - title
  - objective
  - required items
  - optional AI prompt
- Buddy validate path co it nhat mot start checkpoint va outcome ro.

**Student workflow:**

- Student mua collection de co path, khong chi mua bundle.
- Sau purchase, student thay progress/checkpoints.
- Library hien collection trong `Continue learning` voi next checkpoint.

**Success metrics:**

- Collection purchase conversion.
- Path start rate.
- Checkpoint completion rate.
- Attach rate cua resources/tutorials trong collection.
